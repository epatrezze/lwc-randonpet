# RandonPet 🐱🐶

Este é um aplicativo Lightning Web Component (LWC) que exibe fotos aleatórias de gatos e cachorros com base na seleção do usuário.

## Funcionalidades ✨

- Seleção entre gatinhos e doguinhos
- Exibição de imagens aleatórias de gatos e cachorros
- Interface intuitiva com botões e radio buttons

## Tecnologias Utilizadas 💻

- Lightning Web Components (LWC)
- JavaScript
- HTML
- CSS
- APIs externas para obtenção de imagens

## APIs Utilizadas 🌐

- The Cat API - para imagens de gatos
- Random Dog API - para imagens de cachorros

## Estrutura do Projeto 📁

```
src/
├── app.js          # Lógica principal do componente
├── app.html        # Template HTML do componente
├── app.css         # Estilos CSS
└── index.stories.js # Configuração para demonstração
```

## Como Utilizar 🚀

1. Selecione o tipo de animal (gatinhos ou doguinhos)
2. Clique no botão para obter uma imagem aleatória
3. A imagem será exibida na tela
